# 📈 Trading Journal - Gratis Digital Loggbok

En modern, gratis och responsiv trading journal för att spåra och analysera dina trades.

## ✨ Funktioner

### 📊 Instrumentval
- **70+ Förkonfigurerade Instrument** organiserade i kategorier:
  - 💱 **Forex** - 10 populära valutapar (EUR/USD, GBP/USD, etc.)
  - 🥇 **Metaller** - 8 ädelmetaller (Gold, Silver, Platinum, etc.)
  - 💰 **Crypto** - 10 kryptovalutor (BTC, ETH, SOL, etc.)
  - 📈 **Futures** - 10 populära futures (ES, NQ, CL, etc.)
  - 🏢 **Aktier** - 10 stora US-aktier (AAPL, MSFT, TSLA, etc.)
  - 💻 **Nasdaq** - 10 tech-aktier (NFLX, AMD, NVDA, etc.)
- **Fritext-input** - Skriv in vilket instrument som helst

### 📱 Övriga Funktioner
- ✅ Fullt responsiv - fungerar på mobil, surfplatta och dator
- ✅ Mörkt/ljust läge - sparar användarens preferens
- ✅ Lokal lagring - ingen server behövs, data sparas i webbläsaren
- ✅ Export/Import - säkerhetskopiera eller dela din data (JSON)
- ✅ Filtrering - sök på tillgång, typ eller status
- ✅ Statistik - win rate, total P/L, automatiskt uppdaterat
- ✅ Redigering - ändra affärer i efterhand
- ✅ PWA-stöd - kan installeras som en app på mobilen
- ✅ SEO-optimerad

### 🎨 Design
- Modern UI med gradienter och glassmorphism
- Smidiga animationer och hover-effekter
- Visuella kategorier och färgkodning

## 🚀 Deployed på Netlify

Din sajt uppdateras automatiskt när du pushar till GitHub!

## 📝 Användning

1. **Lägg till trade**: Välj instrument, typ (Long/Short), pris, datum
2. **Stäng trade**: Redigera och lägg till exit-pris
3. **Analysera**: Se statistik och win rate
4. **Exportera**: Spara din data som JSON

## 🛠️ Tech Stack

- HTML5
- CSS3 (Modern gradients, animations)
- Vanilla JavaScript
- LocalStorage API
- PWA Support
